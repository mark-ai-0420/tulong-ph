# Agent Handoff: Ponytail Modularization & Monolith Decomposition

## Goal
Decompose TulongPH's monolithic library and UI files into modular, reusable units using the Ponytail principle (smallest structural change that eliminates duplicated code and splits giant multi-step files without adding unnecessary wrapper layers or breaking existing runtime, test, or VM sandbox contracts), and fix legacy `tulongph.gov.ph` strings to use the canonical production URL `https://tulongph.vercel.app`.

Phased Scope and Architectural Constraints:

1. Phase 1 - Core Libraries, Canonical URL Fix, and Route Shell Deduplication:
   - `src/lib/storage.ts`: Keep `storage.ts` as a single self-contained module with its existing top-level imports (`idb-keyval`, `./data/phLocations.ts`, `./gwaTracker.ts`) so all 6 Node `vm` test harnesses (`test-encrypted-backup.mjs`, `test-gwa-tracker.mjs`, `test-ofw-case-tracker.mjs`, `test-treatment-quota-tracker.mjs`, `test-cross-pillar-bridge.mjs`, `test-worker-calculator.mjs`) continue to transpile and run without unexpected `require()` calls. Only deduplicate functions whose semantics are 100% identical:
     - Simple IndexedDB profiles (`PatientProfile`, `RepresentativeProfile`, `MedicalCase`, `Applications`): share internal `saveSimpleRecord<T>(key, data, token)` (`if (token === undefined) await ensureReadyForStorage(); if (typeof window === 'undefined' || wiping || !canWriteDuringRestore(token)) return; await set(key, data);`) and `loadSimpleRecord<T>(key, fallback)` (`await ensureReadyForStorage(); if (typeof window === 'undefined') return fallback; const data = await get<T>(key); return data || fallback;`).
     - Generation-guarded trackers (`TreatmentTracker`, `OFWCaseTracker`, `GWATracker`): share internal `saveTrackedRecord<T>(key, data, token)` (`const expectedGeneration = wipeGeneration; await ensureReadyForStorage(); if (typeof window === 'undefined' || wiping || (token === undefined && expectedGeneration !== wipeGeneration)) return; if (!canWriteDuringRestore(token)) return; await set(key, data);`) and `loadNullableRecord<T>(key)` (`await ensureReadyForStorage(); if (typeof window === 'undefined') return null; return (await get<T>(key)) ?? null;`) for `TreatmentTracker` and `OFWCaseTracker`; share `clearTrackedRecord(key, token)` (`const expectedGeneration = wipeGeneration; await ensureReadyForStorage(); if (typeof window === 'undefined' || wiping || (token === undefined && expectedGeneration !== wipeGeneration)) return; if (!canWriteDuringRestore(token)) return; await del(key);`) across `TreatmentTracker`, `OFWCaseTracker`, and `GWATracker`; and retain `GWATracker`'s explicit `isGWATrackerRecord(data)` validation in `saveGWATracker` (throwing `new TypeError('Invalid GWA tracker record.')` before calling `saveTrackedRecord`) and `loadGWATracker` (`return isGWATrackerRecord(data) ? data : null;`).
     - Leave `saveDocuments`, `EducationSession` (`localStorage` backed), `SharedFamilyContext`, and `WorkerSession` (`workerSessionStore` + migration) with their bespoke logic intact. Preserve `new BroadcastChannel('tulongph-backup')`.
   - `src/lib/triageEngine.ts` and `src/lib/triageStepBuilders.ts`: Deduplicate the repeated `StackingStep` definitions (such as OWWA MedPlus, PCSO MAP, PACe Malacanang, Senate Assist, DSWD AICS, and LGU/Congressional assistance) across `buildPublicDOHTriage`, `buildPublicLGUTriage`, `buildPrivateGLStackingTriage`, and `buildPrivateTransferTriage` using internal step builder helpers in `src/lib/triageStepBuilders.ts` (imported with explicit `.ts` extension `./triageStepBuilders.ts` for Node `--test` compatibility). Preserve 100% identical `calculateAidStacking` output, step numbering, document accumulation, and warning order.
   - `src/lib/pdfGenerator.ts` and `src/lib/pdf/`:
     - Use explicit `.ts` extensions on all relative imports inside `src/lib/pdfGenerator.ts` and `src/lib/pdf/*.ts` so Node `--test` scripts (`scripts/test-pdf-packets.mjs` and `scripts/test-unified-document-vault.mjs`) resolve them directly without a bundler.
     - One-way dependency graph (zero circular imports): `src/lib/pdf/pdfPrimitives.ts` defines and exports the shared low-ink A4 layout primitives (`PAGE_WIDTH`, `PAGE_HEIGHT`, `MARGIN_LEFT`, `MARGIN_RIGHT`, `USABLE_WIDTH`, `drawOfficialHeader`, `drawSectionBanner`, `drawFieldCell`, `drawPacketHeader`, `drawPacketMetadata`, `drawPacketSection`, `drawPacketFieldRow`, `drawPacketKeyValueRows`, `drawPacketTable`, `drawPacketParagraph`, `drawPacketChecklist`, `drawPacketReferenceCards`, `drawPacketFooter`, `ensurePacketSpace`, `packetAscii`, `packetMoney`, `packetLines`, `startPacketContinuationPage`, and `appendVaultAttachments`).
     - `src/lib/pdf/educationPdfBuilder.ts` imports primitives from `./pdfPrimitives.ts` and exports `buildEducationPacketPages(doc, profile, recipient, documents)`.
     - `src/lib/pdf/workerPdfBuilder.ts` imports primitives from `./pdfPrimitives.ts` and exports `buildWorkerWorksheetPages(doc, profile, fields, selection, documents)` plus `type WorkerWorksheetSelection`.
     - `src/lib/pdfGenerator.ts` imports from `./pdf/pdfPrimitives.ts`, `./pdf/educationPdfBuilder.ts`, and `./pdf/workerPdfBuilder.ts`, re-exports `type { WorkerWorksheetSelection }`, and preserves the exact public signatures `generateEducationPacketPdf(profile: StudentEducationProfile, recipient = 'Sa Kinauukulan (To Whom It May Concern)', documents: StoredDocument[] = [], includeVaultAttachments = false): Promise<jsPDF>` and `generateWorkerWorksheetPdf(profile: WorkerProfileInput, fields: WorkerWorksheetFields, selection: WorkerWorksheetSelection = 'all', documents: StoredDocument[] = [], includeVaultAttachments = false): Promise<jsPDF>` in `src/lib/pdfGenerator.ts` containing the exact statement `if (includeVaultAttachments) await appendVaultAttachments(doc, documents);` (verified by `scripts/test-unified-document-vault.mjs`).

   - `src/components/shared/useCivicRouteSync.ts` and Route Shells (`src/app/page.tsx`, `src/app/edukasyon/page.tsx`, `src/app/manggagawa/page.tsx`): Extract shared `#privacy-cleared` hash toast handling and `tulong_lang` `localStorage` synchronization into `src/components/shared/useCivicRouteSync.ts`.

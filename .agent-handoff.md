# Agent Handoff: Plain-Language & Mass-Usability Simplification (Medical, Education, Worker)

## Goal
Simplify TulongPH across all three pillars (**Medikal**, **Edukasyon**, **Manggagawa**) so an everyday Filipino household member, hospital watcher, student, or worker can navigate every step without needing to understand government bureaucracy, legal jargon, or technical agency formulas:

1. **Shared Plain-Language Components (`src/components/shared/PlainLanguageGuide.tsx`)**:
   - Create `QuickStartActionCard` ("Unang Gagawin Ngayong Araw: 1-2-3 Quick Guide") rendered at the top of Step 3 across Medical, Education, and Worker:
     1. *Saan Unang Pupunta* (exact desk, office, or online portal based on the active profile/scenario)
     2. *Anong Mga Papel ang Dapat Hawak* (top 3 immediate documents)
     3. *Ano ang Sasabihin sa Counter* (exact conversational script in quotes)
   - Create `PlainLanguageGlossaryCard` ("Ano ang ibig sabihin ng mga salitang ito? (Simpleng Paliwanag)"), a compact collapsible `<details>` card explaining unavoidable terms per pillar (`Guarantee Letter / GL`, `Running Bill / SOA`, `Clinical Abstract`, `No Balance Billing / NBB`, `Barangay Indigency`, `SUC / LUC`, `TES / TDP`, `DOLE SEnA`, `SSS MSC`, `ECC`).
   - Support all 4 languages (`taglish`, `cebuano`, `ilocano`, `en`) and contain zero em-dash characters.

2. **Medical Triage Simplification (`src/components/TriageWizard.tsx` & `src/lib/i18n.ts`)**:
   - Clarify Step 1 and Step 2 labels/descriptions to lead with plain conversational terms followed by the official acronym in parentheses (e.g., *"Running Bill / Kwentada ng Ospital (SOA)"*, *"Walang Babayaran sa Charity Ward (No Balance Billing / NBB)"*, *"Libreng Tawag sa DOH Para sa Paglipat ng Ospital (Hotline 1555)"*).
   - In Step 3:
     - Render `QuickStartActionCard` and `PlainLanguageGlossaryCard` at the top of the Step 3 results view.
     - Keep the In-Situ Malasakit Desk / Hospital Transfer Playbook and Step-by-Step Aid Stacking Roadmap immediately visible below.
     - Wrap secondary tools (`GenericPrescriptionGuideCard`, `GLCooldownTrackerCard`, `TreatmentQuotaTrackerCard`) inside a clean collapsible `<details>` section below the main roadmap (*"Iba pang Pantulong na Tools sa Gamot, Dialysis/Chemo, at Guarantee Letter (Optional)"*) while ensuring existing unit and E2E tests that interact with them still pass (or open the `<details>` if needed).

3. **Education Wizard Simplification (`src/components/education/EducationWizard.tsx`)**:
   - **Step 1**:
     - Replace raw acronym pills (`Public / state-run TVI`, `SUC / LUC`) with plain conversational labels (*"Public TESDA / Tech-Voc School (Public / state-run TVI)"*, *"State Univ / Public College (UP, PUP, PLM - SUC / LUC)"*, *"Private School / College / University"*).
     - Auto-detect `location` (`NCR` / `HUC` / `other`) when a City/Municipality is selected (e.g. NCR cities -> `NCR`, Highly Urbanized Cities like Cebu City, Davao City, Baguio City, Iloilo City, Cagayan de Oro City, Zamboanga City, Angeles City, Bacolod City, etc. -> `HUC`, others -> `other`), and tuck `#edu-location` inside an optional `<details>` drawer (*"I-edit ang klasipikasyon ng lugar ng paaralan (Optional)"*).
   - **Step 2**:
     - Tuck `#edu-daily-wage` inside an optional `<details>` drawer (*"I-edit ang minimum wage sa lugar (Optional)"*) since it is already auto-populated from the City/Municipality selector.
     - Group the Step 2 eligibility checkboxes into two structured visual cards:
       - **Card 1: 1. Tungkol sa Pamilya at Kalagayan** (`is4PsOrListahanan`, `isSoloParentOrDependent`, `isPWD`, `isOFWDependent`, `isCoconutFarmerDependent`, `isGSISDependent`, `inCrisis`, `inMunicipalityWithNoSUC`)
       - **Card 2: 2. Tungkol sa Grado at Kurso** (`isIncomingFirstYear`, `isPublicHSGradTop10`, `isPriorityCourse`, `isDOSTAccreditedProgram`, `willingToSignReturnService`, `hasReviewCenterOrPRCReceipt`, `isWithinResidencyLimit`)
     - Rewrite technical checkbox labels into conversational language across all 4 languages (e.g., explain residency limit as *"Regular na estudyante at hindi pa lampas sa takdang taon ng kurso (Within normal program residency)"*).
   - **Step 3**:
     - Render `QuickStartActionCard` and `PlainLanguageGlossaryCard` at the top of Step 3 above the matched programs list.
     - Wrap `GWATrackerCard` and `ScholarshipCalendarCard` inside a collapsible `<details>` section (*"Pang-monitor ng Grado at Deadlines ng Scholarship (Optional)"*) positioned below the matched programs list.

4. **Worker Wizard Simplification (`src/components/worker/WorkerWizard.tsx`)**:
   - **Step 1**:
     - Automatically sync `averageMonthlySalaryCredit` and `highestSixMonthlySalaryCredit` (`Math.min(20000, Math.max(5000, Math.round(value / 500) * 500))` when `value > 0`, or `0`) whenever `monthlySalary` changes unless the user manually edits the override inputs. The current official SSS contribution table sets a PHP 5,000 minimum MSC effective January 2025, so the earlier PHP 4,000 floor was outdated. Automatically sync `pagibigTAV` (`months * 400`) when `pagibigContributionMonths` changes unless manually overridden.
     - Dynamically filter Step 1 inputs by `scenario`:
       - Hide `#worker-contributionMonths` when `scenario === 'wages'` or `scenario === 'livelihood'`.
       - Only show `#worker-pagibigContributionMonths` when `scenario === 'loans'`.
     - Tuck `#worker-averageMonthlySalaryCredit`, `#worker-highestSixMonthlySalaryCredit`, and `#worker-pagibigTAV` inside an optional `<details>` drawer (*"I-edit ang eksaktong SSS / Pag-IBIG record (Optional)"*), keeping the existing estimate buttons inside that drawer so users or tests can still use them.
   - **Step 2**:
     - Rewrite dense legal/actuarial phrases (`contingency semester`, `PPD schedule-of-loss duration`, `authorized cause`) into conversational questions with plain examples across all 4 languages.
     - Tuck `#worker-loanProratedDays` (`0-62 days`) and `#worker-gsisAdvanceInsuranceMonths` inside an optional `<details>` drawer (*"I-edit ang eksaktong kaltas sa loan disclosure (Optional)"*).
   - **Step 3**:
     - Render `QuickStartActionCard` and `PlainLanguageGlossaryCard` at the top of Step 3 above the matched benefits and claim checklists.

5. **E2E & Unit Test Synchronization (`scripts/test-e2e-autocompute.mjs` and affected unit tests)**:
   - Update `scripts/test-e2e-autocompute.mjs` (and any unit test that inspects wizard source strings) so tests open the optional `<details>` override drawers when testing manual override inputs (`#edu-location`, `#edu-daily-wage`, `#worker-averageMonthlySalaryCredit`, `#worker-highestSixMonthlySalaryCredit`, `#worker-pagibigTAV`, `#worker-loanProratedDays`, or collapsible Step 3 tool cards), while also verifying automatic bracket computation works out of the box.

6. **Delegated cross-tab idle test follow-up (`scripts/test-e2e-autocompute.mjs`)**:
   - In `runCrossTabIdleTests`, scroll `#worker-monthlySalary` into view and allow pending compositor scroll events to dispatch before each clock fast-forward around the active-tab edit.

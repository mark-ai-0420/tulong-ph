# Agent Handoff: Desktop & Large-Screen Navigation Layout Remediation

## Goal
Fix responsive flexbox collision in `src/components/Navbar.tsx` on larger desktop screens (1024px to 1440px and ultrawide viewports), where the desktop segmented navigation rail (`Gabay at Kompyutasyon`, `I-print ang Forms`, `Direktoryo at Desks`) overlapped the privacy badge (`• Naka-save sa device`):

1. **Root Cause**:
   - The header container was capped at `max-w-7xl` (`1216px` inner width at `lg:px-8`) across all desktop viewports $\ge 1280\text{px}$.
   - At `xl:` (1280px), three items expanded simultaneously: the privacy badge (`159px`), utility trash button label (`+110px`), and language toggle full label (`+80px`), while the central `navRail` required up to `725px` in regional languages (Cebuano/Ilocano).
   - Because `navRail`, `utilityCluster`, and `privacyPill` had `shrink-0`, but `logoGroup` lacked `shrink-0` and lacked overflow clipping, flexbox shrunk `logoGroup` below its content width, projecting the privacy pill outward directly under the navigation rail by 26px to 79px.

2. **Remediation Strategy**:
   - Add `shrink-0` to `logoGroup` (`shrink-0 flex items-center gap-2.5 sm:gap-3`) so flexbox never shrinks the logo group.
   - Expand header container responsiveness: `<div className="max-w-7xl 2xl:max-w-screen-2xl mx-auto px-4 sm:px-6 lg:px-6 xl:px-8">`.
   - On `lg` and `xl` viewports (1024px-1535px), hide the logo tagline (`hidden sm:block lg:hidden 2xl:block`), saving ~75px.
   - Make the privacy pill responsive: display concise label `• Naka-save` / `• Local` on `xl:` (`inline 2xl:hidden`) and full label `• Naka-save sa device` / `• Saved locally` on `2xl:` (`hidden 2xl:inline`), saving ~70px.
   - Adjust `navRail` button padding and font size responsively: `px-2.5 xl:px-3.5 py-2 xl:py-2.5 text-xs xl:text-sm gap-1.5 xl:gap-2`.
   - In utility cluster, keep `Burahin ang Data` label visible on `2xl:` (`hidden 2xl:inline`), keeping a clean 44px icon button between 1024px and 1535px; show `compactLanguageNames[language]` up to `2xl`, displaying full label at `2xl:inline`.
   - Ensure zero overlap across 1024px, 1200px, 1280px, 1366px, 1440px, and 1920px in all 4 languages (`taglish`, `cebuano`, `ilocano`, `en`).
   - Zero em-dash characters in any file.
